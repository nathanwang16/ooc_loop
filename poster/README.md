## How the bar chart was generated

The cross-topology summary chart is produced by
`scripts/plot_cross_topology_summary.py` in the source repository. It reads
`evaluations.json` from each BO state directory and selects the lowest L2 over
feasible records. Re-run after any BO campaign refresh.

## Reproducibility

Every figure is generated by a versioned script in the source repository:
- Schematics → `scripts/visualize_topology_candidates.py`
- Phase-2 scan → `scripts/diagnostic_ladder_scan.py`
- Per-topology Sobol / local sensitivity / tolerance → `scripts/run_interpretability.py`
- Cross-topology bar chart → `scripts/plot_cross_topology_summary.py`

Full run logs, BO state checkpoints, and per-evaluation JSONL are not bundled
here (they are large); they live in
`examples/tumor_chip_linear_gradient/data/results/` in the source repository.
